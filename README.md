# The Greatest Concrete Solutions

Premium Next.js website for The Greatest Concrete Solutions LLC in Columbus, Georgia.

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production build

```bash
npm run build
npm start
```

## Netlify deployment

Push this folder to GitHub, import the repository into Netlify, and use:

- Build command: `npm run build`
- Publish directory: `.next`
- Node version: `22`

The included `netlify.toml` supplies these settings automatically.
